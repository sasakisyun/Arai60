以下のコードが分かりやすかった．
```py
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        nums_to_count = {}
        for num in nums:
            nums_to_count[num] = nums_to_count.get(num, 0) + 1
        top_k_count = []
        for num, count in nums_to_count.items():
            heapq.heappush(top_k_count, (count, num))
            if len(top_k_count) > k:
                heapq.heappop(top_k_count)
        return [num for count, num in top_k_count]
```
- 時間計算量はnlogk,とある．まずここがわからない．
  - nums_to_countつくる: n，とある．ここはわかる．
  - pushとかpopでlogkというのはなんでなんだろうか．中身がわかっていないので，わからない．
  - アルゴリズムイントロダクションの該当ページを参照．Pythonのheapqは最小ヒープを用いて実装されている．
      - heappopするときは，一番上の要素を取り出す．そこに，配列の末尾の要素を代わりに突っ込む．
      - それをまた最小ヒープにするために，その要素を滑り降りさせる．木の高さはO(logn)くらいだから，計算にO(logn)かかる．
      - 本を読んでAIに質問して，だいたい上のような仕組みだなあという認識を得た．
- 空間計算量はnである．nums_to_countがnで，heapにk．最後の配列作成にk．これは納得．

次にこれも読んだ．
```py
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        freq_dict = Counter(nums)
        freq = [(count, num) for num,count in freq_dict.items()]

        def quickselect(arr, k):
            if not arr:
                return []

            pivot = random.choice(arr)
            lows = [x for x in arr if x[0] < pivot[0]]
            pivots = [x for x in arr if x[0] == pivot[0]]
            highs = [x for x in arr if pivot[0] < x[0]]
            
            
            if k <= len(highs):
                # highが大きすぎるので、そこから絞るケース
                return quickselect(highs, k)
            elif k <= len(highs) + len(pivots):
                # high全てと「自分と同じ値のもの」を何個か返すとちょうどOKなケース
                return highs + pivots[:k - len(highs)]
            else:
                # highと自分と同じ値のものでもまだ足りないので、足りない分だけlowから探すケース
                return highs + pivots + quickselect(lows, k - len(highs) - len(pivots))

        top_k = quickselect(freq, k)
        return [num for count, num in top_k]
```
- Counter(nums)で，要素数を数えて辞書の形で返してくれる．
- クイックセレクトはクイックソートの派生．クイックソートと違って，必要ない部分は捨てていくので，計算量がO(N)に落ちる．
- 時間計算量O(N)
    - Counter(nums)がO(N)，freqへの変換がO(M)，クイックセレクトが平均O(M)
- 空間計算量O(N)
- 最初のif not arr はなんで必要なのかわからない．
