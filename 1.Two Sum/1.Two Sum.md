## ステップ１　自分で解く
- nums[1] + nums[2], nums[1] + nums[2], ..., nums[2] + nums[3], ...と調べていけばいい．
- forを二重ループすれば答えは出そうだな．と思った．他の解答は思いつかない．

最初に書いた答えが以下．3分くらいでかけた．
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)):
            for j in range(i, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i,j]       
```
- wrong answerになってしまった，理由を検討したら，jのループがiでなくi+1からにする必要があったと気づいた．そこだけ修正したのが以下．
- 修正はすぐにできた．
  
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i,j]      
```
- 通った.時間計算量はO(n^2)，空間計算量はO(１)．

## ステップ2　読みやすくする，他人のコードを読む
- https://github.com/h1rosaka/arai60/blob/11_-1.-Two-Sum/1.%20Two%20Sum.md

```Python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]: 
        num_to_index = dict() 
        # 一つずつ辞書に追加する
        for i, num in enumerate(nums): 
            # 追加するときに、パートナーがすでに辞書に入ってないか確認し、入ってたら、return
            partner = target - num
            if partner in num_to_index:
                return [num_to_index[partner], i]

            num_to_index[num] = i
```
- 辞書を使って時間計算量をO(N)にしている．
- enumerateという関数を初めて知った．要素のindexと値をペアで取得できる．
- 空間計算量O(N)
- iに意味を持たせて，num_index等にしてもいいと思った．
- 最後から2行目の空行はあったほうがいいのだろうか？

- https://github.com/garunitule/coding_practice/blob/1/HashMap/1/memo.md
  
```python
from collections import defaultdict

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        num_to_indices = defaultdict(list)
        for i in range(len(nums)):
            num_to_indices[nums[i]].append(i)
        
        for i in range(len(nums)):
            if target - nums[i] in num_to_indices:
                indices = num_to_indices[target - nums[i]]
                for j in indices:
                    if i != j:
                        return [i, j]
        
        return []
```
- defaultdictとは何か知らなかったので調べた．
    - defaultdict(list)とすると，存在しないキーにアクセスした時空のリストを生成してくれる．
    - listをintにすると0が生成される．setだと空のリストが生成される．
- indicesという単語を知らなかった．インデックスという意味のようだ． num_to_indicesは，数字とその索引の組の辞書という意味のようだ．
- indicesだけ複数形なのは，同じ数が何度も出ることがあるのでいくつもindiceを登録することになることがあるからだろう．

## ステップ3 3回連続で書く
ステップ2の最初のコードがわかりやすかったので，3回続けて書いた．

```py
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        num_to_index = dict()
        for i, num in enumerate(nums):
            partner = target - num
            if partner in num_to_index:
                return [num_to_index[partner], i]
            num_to_index[num] = i
```
