## ステップ1

- 毎回リストに値を追加して、sort()を使って並び替えれば良いのではないかと思ったけど、明らかに計算が過剰な気がする。新たに追加する数以外、小さい順に並んでいるのに、またsort()を使うのは非効率だろう。そもそも上位k個の値のみ知っていればいいのだし。
効率のいい解き方は思いつかないので、解答を見ることにする。
- 参照した解答:https://github.com/garunitule/coding_practice/blob/703/Heap/703/memo.md
- 優先度付きキューというものは聞いたことがあったが、heapqモジュールの使い方は知らなかったので、解答で使用しているものの使い方を調べて理解した。参照した解答は以下。

```python
import heapq
class KthLargest:
    heap_nums: List[int]
    k: int

    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.heap_nums = heapq.nlargest(k, nums)
        self.heap_nums.sort()     
 
    def add(self, val: int) -> int:
        if len(self.heap_nums) < self.k:
            heapq.heappush(self.heap_nums, val)
        else:
            heapq.heappushpop(self.heap_nums, val)
        return self.heap_nums[0]
```
- 今回使っているのは、nlargestという関数。上位k個の数字を取ってきてくれる。それより小さい数字の情報は必要ないので、計算を効率化するために役立つ。
- 数字を追加するときは、heappushやheappushpopを使う。前者は優先度付きキューに数字を追加してくれる。後者は優先度付きキューに数字を追加したのちに、最も小さいものをpopする。数字がk個より小さい時は前者、そうでない時は後者を使うといい。

## ステップ2
- nlargestは、上位k個の数字を取ってきてくれるのだが、それを大きい順に返すようだ。であれば、sortを使うより、単にreverseした方がいいではないか。
- 変数名はこれで良いのだろうか。heap_numsと言われると、上位k個を保持している感じがしないかもしれない。他の人のコードを読んでいて、top_k_valsなどを使っている人がいたのでそうする。

```py
import heapq
class KthLargest:

    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.top_k_vals = heapq.nlargest(k,nums)
        self.top_k_vals.reverse()

    def add(self, val: int) -> int:
        if len(self.top_k_vals) > self.k:
            heapq.heappush(self.top_k_vals,val)
        else:
            heapq.heappushpop(self.top_k_vals,val)
        return self.top_k_vals[0]
```
