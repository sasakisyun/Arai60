# 206.Reverse Linked List
- 問題：https://leetcode.com/problems/reverse-linked-list/
- 言語：Python

## Step1
- リストを入れ替えるだけ。かなり簡単そうだ。
- スタックを使って、スタックに全部nodeのvalueを入れて、入れ終わったら１つずつ出して新しいLinkedListを作成する。
- 最初の部分をどうするか。前に見たdummyを使ってやるのがいいだろう。
- dummyから始めて、LinkedListを作ったら、次々新しいnodeを作成して、dummy.nextをreturnすればいいだろう。
- 書いて提出したら、一回でアクセプトされた。

```python

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        node = head
        dummy = ListNode(0)
        stack = []
        while node:
            node_value = node.val
            stack.append(node_value)
            node = node.next
        node = dummy
        while len(stack) > 0:
            new_val = stack.pop()
            node.next = ListNode(new_val)
            node = node.next
        return dummy.next
```
- 時間計算量：$O(n)$
- 空間計算量：$O(n)$

- 自分のコードを整えようと思ったが、変数名nodeを変えた方がいいかも知れないということ以外思いつかなかった。
- nodeを入れ替えていく解法を試してみた

```py
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        node = head
        prev = None
        while node:
            next_node = node.next
            node.next = prev
            prev = node
            node = next_node
        return prev
```
- 最初は難しかったが、紙に書いてみたら理解できた。
- 今のnodeから出てる矢印が刺さってる次のnodeに「これは次のnodeです」と目印を立てておいて、今のnodeの矢印を前のnodeに移す。
- 今のnodeに「これは前のnodeです」という目印を移しておく。
- 次のnodeに目印が付いているので、それに進む。
- また次のnodeに目印を移す。前のnodeに目印が付いているので、今のnodeの矢印をそっちに移す。
- 以下繰り返し。
- 実はreturnで間違えた。return nodeとしたら通らなかった。最終的にnode = Noneになって終わる。prevをそのまま利用してしまうのがいいみたいだ。

## step3
- nodeを繋ぎかえる解き方は初見なので、3回連続で書いてみる

```py
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        node = head
        prev = None
        while node is not None:
            next_node = node.next
            node.next = prev
            prev = node
            node = next_node
        return prev
 ```
- while nodeではなくwhile node is not Noneの方がいいと言われていたのを思い出した。
- 3回書くのはスムーズにできた。
- これだと新しいLinkedListを使っていないので、空間計算量が$O(n)$で済む。
