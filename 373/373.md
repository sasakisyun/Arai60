```py
class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:

        candidates = [(nums1[0] + nums2[0], 0, 0)]
        seen = set([(0,0)])
        smallest_pairs = []

        def need_to_be_added(index1, index2):
            if len(nums1) <= index1 or len(nums2) <= index2:
                return False
            if index1 == 0 or index2 == 0:
                return True
            return (index1 - 1, index2) in seen and (index1, index2 - 1) in seen


        def add_if_necessary(index1, index2):
            if need_to_be_added(index1, index2):
                heapq.heappush(candidates, (nums1[index1] + nums2[index2], index1, index2))
               

        while len(smallest_pairs) < k:
            _, index1, index2 = heapq.heappop(candidates)
            smallest_pairs.append([nums1[index1], nums2[index2]])
            seen.add((index1, index2))
            add_if_necessary(index1 + 1, index2)
            add_if_necessary(index1, index2 + 1)
        return smallest_pairs
```

- なんだかややこしいと感じた。重複のないようにcandidatesに入れて、そこからpopして、smallest_pairsにappendする。
- 重複を避ける方法もややこしい。

```python
import heapq

class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:
        result = []
        min_heap = [(nums1[0] + nums2[0], 0, 0)]
        visited = set((0, 0))

        while len(result) < k:
            _, i, j = heapq.heappop(min_heap)
            result.append((nums1[i], nums2[j]))

            if i + 1 < len(nums1) and (i + 1, j) not in visited:
                heapq.heappush(min_heap, (nums1[i + 1] + nums2[j], i + 1, j))
                visited.add((i + 1, j))
            
            if j + 1 < len(nums2) and (i, j + 1) not in visited:
                heapq.heappush(min_heap, (nums1[i] + nums2[j + 1], i, j + 1))
                visited.add((i, j + 1))
        
        return result
```
- 分かりやすいと感じた。次にresultに入りうるものをheapqに入れておく。heapqから一番和が小さいものを取り出したら、候補がまた増えるのでそれもheapqに入れる、この繰り返し。
- 似たようなものを見たことがなかったので思いつかなかったのかもしれない。
- 改善点を検討するも、特に思いつかない。極めて分かりやすいと感じる。強いていうなら、min_heapではなく、次の候補的な名前にしてもいいかもしれない。

## ステップ3 3回連続で書く

```python
import heapq
class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:
        result = []
        min_heap = [(nums1[0] + nums2[0], 0, 0)]
        visited = set((0,0))

        while len(result) < k:
            _, i, j = heapq.heappop(min_heap)
            result.append((nums1[i], nums2[j]))

            if i + 1 < len(nums1) and (i + 1,j) not in visited:
                heapq.heappush(min_heap, (nums1[i + 1] + nums2[j], i + 1, j))
                visited.add((i + 1, j))

            if j + 1 < len(nums2) and(i,j + 1) not in visited:
                heapq.heappush(min_heap, (nums1[i] + nums2[j + 1], i, j + 1))
                visited.add((i, j + 1))

        return result
```

- アルゴリズムは自身の直感に合っていたので、一度読んだら迷わず書けたが、文法面で何度かミスをした。
    - 括弧を二重にするべきところで二重にしない。
    - heappushするときに、2つ目の要素に括弧をつけない(3つpushしようとしてしまっていて明らかにダメ）
    - heapq.heappushではなく、min_heap.heappushなどと書いてしまう
- 上記のようなミスを何度かしてしまった。
